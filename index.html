Расход топлива

Введите пробег. Норма и факт считаются сразу.

Значения в полях стоят для примера. Пустое поле считается нулём.

Одометр после поездки—км
Расход по норме—л
Расход по факту—л
Остаток на конец—л

Факт равен норме, округлённой до десятых по правилам математики. Остаток = на начало + заправка − расход по факту.

Топлива не хватает: расход больше, чем было в баке и заправлено.
